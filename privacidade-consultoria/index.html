Privacidade

Política de Privacidade da consultoria

Como a UseUsa trata os dados que você envia pelo formulário de contato deste site.

Atualizada em 17 de novembro de 2026.

Dados coletados

Só o que você preenche no formulário: nome, nome da empresa, cargo, faturamento médio mensal, e-mail, WhatsApp e mensagem. Cargo e faturamento são opcionais.

Para evitar envios automáticos em excesso, guardamos também um código gerado a partir do endereço IP de quem enviou. O IP em si não é guardado.

Para que usamos

Para responder ao seu contato e, se fizer sentido para você, propor um serviço de consultoria. Não usamos os seus dados para nenhuma outra finalidade.

Onde ficam armazenados

Num banco de dados no Supabase, com acesso restrito ao sistema que recebe o formulário. Quando um contato chega, um aviso com os dados enviados vai para o e-mail da UseUsa.

Compartilhamento

Não vendemos nem compartilhamos os seus dados com terceiros.

Por quanto tempo

Guardamos os dados por até 12 meses a partir do envio. Depois disso, eles são apagados.

Como pedir a exclusão

Escreva para contato@useusa.com.br pedindo a exclusão. Informe o e-mail usado no formulário para localizarmos o seu contato. Você também pode pedir, pelo mesmo endereço, para ver ou corrigir os seus dados.
